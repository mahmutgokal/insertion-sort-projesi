Bu projede Insertion Sort yöntemini kullanarak verilen diziyi küçükten büyüğe sıraladım.

Başlangıç dizisi:
[22, 27, 16, 2, 18, 6]

Adım adım sıralaması:

1. [22, 27, 16, 2, 18, 6]
2. [16, 22, 27, 2, 18, 6]
3. [2, 16, 22, 27, 18, 6]
4. [2, 16, 18, 22, 27, 6]
5. [2, 6, 16, 18, 22, 27]

Big-O gösterimi O(n²).

18 sayısı dizinin ortalarında olduğu için ortalama durum olarak değerlendirilir.
